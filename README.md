# Wedding planner

A private wedding planner for two people: a web app, a native Android app and one backend.

What it is meant to do, the technology and the order it is built in are in
[`docs/specs/S01-product-scope.md`](docs/specs/S01-product-scope.md). So far the web app has sign-in, the plan as a
list and as a Gantt chart, tasks, priorities and a home page; the Android app is a first screen.

- Working on it: [`CLAUDE.md`](CLAUDE.md) — the layout, the commands and the gate every change has to pass.
- Running it as a container: [`docs/deployment.md`](docs/deployment.md).
- Why things are the way they are: [`docs/decisions.md`](docs/decisions.md).
